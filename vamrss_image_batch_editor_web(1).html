＊VAMRSS(IMAGE BATCH EDITOR)

Batch Image Editor

画像をドラッグ＆ドロップして、Crop / Resize / Convert をまとめて実行します。処理はブラウザ内で完結し、画像は外部へ送信されません。

Input
DROP IMAGES OR FOLDER

jpg / jpeg / png / webp / tif / tiff / bmp に対応します。TIFFはブラウザにより読み込めない場合があります。

Output
Output Folder
Not selected
Naming
OriginalName__PresetName.ext / duplicate: _001, _002...
Browser Note
Web版では元フォルダへの自動保存はできません。Chrome / Edge の場合は Choose Output Folder で保存先を選択できます。
Log

Preview / Create Preset

プレビューは左側リストの先頭画像を使用します。100%モードではスクロールと移動ボタンで確認できます。
