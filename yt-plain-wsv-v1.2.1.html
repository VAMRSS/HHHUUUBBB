Search Note

YT Plain uses the YouTube Data API only for search and metadata retrieval. It does not sign in to your YouTube account, read watch history, or use your personal recommendation feed. “Oldest” uses adaptive time-window splitting: sparse searches usually finish in one call, while only saturated periods are divided further. Completed searches are cached on this device for 24 hours. The displayed daily count tracks search.list calls made by this browser only; it is not the authoritative Google Cloud quota total.
